# Tableau parcial con regiones coloreadas

La imagen colorea las nueve regiones de la matriz `T` segun los bloques Tableau y sus dimensiones (7, 7, 5). Los valores se leen del artefacto `tableau_partial_10hz.json`, ensamblado por la herramienta del proyecto para las siete ramas de dos terminales a 10 Hz.

El op-amp ideal U1 fue excluido expresamente porque el ensamblador del proyecto requiere MNA para U1. La matriz no representa el circuito completo.
